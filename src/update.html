How to update

ActiveReader is installed as an unpacked folder, so Chrome cannot replace it automatically. Updating takes about a minute:

  1. Download the latest .zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Reload on ActiveReader if the files were replaced in place, or Load unpacked to point at the new folder.
  4. Your settings, API key and vocabulary are kept — they live in Chrome storage, not in the folder.

Update settings

ActiveReader reads only the version field from this project's manifest.json on GitHub. No personal data is sent, and you can turn checking off at any time.
