How to update

Update now fetches every file from this GitHub repository and writes it into the folder above, then reloads ActiveReader by itself. The first time, Chrome asks you to pick the folder the extension is loaded from (the one containing manifest.json) and to allow writes to it. The manual steps below are the fallback:

  1. Download the latest .zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Reload on ActiveReader if the files were replaced in place, or Load unpacked to point at the new folder.
  4. Your settings, API key and vocabulary are kept — they live in Chrome storage, not in the folder.

Update settings

Checking reads only the version field of this project's manifest.json on GitHub. Pressing Update now additionally downloads the repository's files (via api.github.com and raw.githubusercontent.com) and writes them into the folder you linked. No personal data is sent, and you can turn checking off at any time.
