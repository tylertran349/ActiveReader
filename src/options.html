AI provider

Quiz generation, answer grading and (optionally) translation use one AI model. Choose Google Gemini, or point ActiveReader at any OpenAI-compatible custom API.

Get a free key from Google AI Studio. Your key is stored in Chrome sync storage and is only ever sent to Google.

The model ID is free text, so new Gemini models work the moment Google releases them — no extension update needed. Leave it blank and ActiveReader will pick one from the live list, or use Fetch models to choose yourself.

Enter any OpenAI-compatible base URL and model ID. For the Command Code Provider API (GOAT plan), use https://api.commandcode.ai/provider/v1 and deepseek/deepseek-v4.1-flash. The host must be allowed in manifest.json.

Type any model ID the provider supports — suggestions are optional. Fetch models fills the list and updates the thinking levels when the model is selected.

Levels are read from the model's capabilities. The model's default is selected unless you choose another level.

Updates

ActiveReader checks this GitHub project for a newer version. Update now goes one step further: it fetches the extension's files from the repository and writes them straight into the folder you loaded the extension from, then reloads it. The first time, Chrome asks you to pick that folder and grant write access. Only GitHub is contacted — no personal data is sent.

Backup & restore

ActiveReader keeps a spare copy of your settings inside the browser and restores them automatically if they go missing after a clean. For a full profile clean (for example with PrivaZer), also download a backup file and keep it somewhere safe — it also saves your vocabulary and contains your API keys.
