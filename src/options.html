Gemini AI

Quiz generation and (optionally) translation use the Google Gemini API. Audio and Google Translate work without a key. Get a free key from Google AI Studio. Your key is stored in Chrome sync storage and is only ever sent to Google.

The model ID is free text, so new Gemini models work the moment Google releases them — no extension update needed. Leave it blank and ActiveReader will pick one from the live list, or use Fetch models to choose yourself.

Updates

ActiveReader checks this GitHub project for a newer version. Chrome cannot install a newer copy of an unpacked extension by itself, so when an update is found you get a one-click download and instructions. Only the version number is read — no personal data is sent.

Backup & restore

ActiveReader keeps a spare copy of your settings inside the browser and restores them automatically if they go missing after a clean. For a full profile clean (for example with PrivaZer), also download a backup file and keep it somewhere safe — it also saves your vocabulary and contains your Gemini API key.
